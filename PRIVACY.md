# Privacy Policy — Refined Recurse

_Last updated: July 17, 2026_

Refined Recurse is a browser extension that applies small quality-of-life
tweaks to [recurse.com](https://www.recurse.com).

## Data collection

Refined Recurse **does not collect, store, transmit, or share any user data.**

- It makes no network requests.
- It reads no personal information, browsing history, or page content.
- It uses no analytics, tracking, cookies, or third-party services.
- It contains no remote code; all of its code ships inside the extension package.

## What the extension does

The extension runs a content script only on `recurse.com` pages. That script
adjusts the page's styling and layout locally in your browser — for example,
restoring the drag-to-resize handle on the general-note comment box. All of this
happens on your device and nothing leaves it.

## Permissions

The extension declares access to `recurse.com` solely so its content script can
run on those pages. It requests no other permissions.

If this policy changes, the updated version will be posted at this URL with a new
